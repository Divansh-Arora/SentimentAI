# SentimentAI: Movie Review Sentiment Analysis Using LSTM

## 1. Project Overview
SentimentAI is a deep learning project that classifies English-language movie reviews as **positive** or **negative**. It uses the IMDb dataset and a Bidirectional Long Short-Term Memory (BiLSTM) network to learn patterns in review text. A Streamlit interface allows users to enter a review and receive a prediction.

## 2. Problem Statement
Reading and categorizing thousands of movie reviews manually is time-consuming. This project investigates whether a recurrent neural network can learn sentiment patterns from labeled reviews and automatically classify unseen reviews.

## 3. Project Objectives
- Prepare and explore a labeled movie-review dataset.
- Build an LSTM-based binary text-classification model.
- Evaluate the model using appropriate classification metrics.
- Develop a simple interface for testing custom reviews.
- Document limitations and opportunities for improvement.

## 4. Dataset Description
**Dataset:** IMDb Dataset of 50K Movie Reviews  
**Source:** [Kaggle dataset page](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

The dataset contains movie-review text and a sentiment label. The labels are `positive` and `negative`. The expected CSV columns are:
- `review`: the text of the movie review
- `sentiment`: the sentiment label

Download the CSV from Kaggle and place it at `data/IMDB Dataset.csv`.

### 5.10 Evaluation Metrics

- **Accuracy:** overall proportion of correct predictions.
- **Precision:** proportion of predicted positive cases that are actually positive.
- **Recall:** proportion of actual positive cases correctly identified.
- **F1-score:** harmonic mean of precision and recall.
- **Confusion matrix:** counts of true positives, true negatives, false positives, and false negatives.

### 5.14 Limitations

## 8. Setup and Execution

### Prerequisites
- Python 3.11 recommended
- Internet access to download the Kaggle dataset
- Enough disk space for the dataset, Python packages, and model artifacts

### Windows PowerShell
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### Download and place the dataset
Download the CSV from the Kaggle link above and save it as:
`data/IMDB Dataset.csv`

### Train the model
```powershell
python train.py
```

### Run the web app
```powershell
streamlit run app.py
```
